# 提交后演示修复：混合咨询遗漏健康描述

## 用户报告与原因

输入：`换的猫粮什么时候到？我家猫最近食欲不好`

旧版命中“什么时候到”“猫粮”，却未识别“食欲不好”，路由为订单并提前返回。因此不是用户操作错误，也不是API超时；该路径没有调用Hy3。

## 修复范围

- 路由复用症状抽取词表，防止两份词表不一致。
- 增加食欲不好、食欲不佳、胃口不好、胃口不佳、没胃口、吃得少等表达。
- 混合咨询进入追问时，明确显示已识别健康描述及订单能力限制。
- 不声称关键词规则能够覆盖任意自然语言表达。

## 验证

`python -m pytest tests/test_final_submission.py -q`：10项通过。

新增测试覆盖用户原句和5种相关表达；纯订单仍走订单分支。Streamlit应用测试使用离线模式，确认原句显示年龄、持续时间、精神状态3个问题；提交“成年，3岁”“今天上午开始”“精神正常”后生成含食欲下降的报告，未出现页面异常。这是交互功能验证，不是医疗有效性验证，也不冒充真实API测试。

另对原句和上述3项补充信息执行了一次真实Hy3管线测试：路由为mixed，生成报告，剩余追问0个，记录到模型调用1次，调用错误0个，拦截字段0个。它是单例连通性检查，不计入原批量评测成绩。
