# 2 分钟 Demo 录制脚本

录制前双击仓库里的 `start_demo.cmd`，或运行：

```powershell
.\.venv\Scripts\python.exe -m streamlit run streamlit_demo.py --server.address 127.0.0.1
```

打开 http://127.0.0.1:8501，选择“Hy3 在线”。先试跑一次确认页面显示“本轮 Hy3 调用成功”；不要录制 `.env`、密钥、控制台账户页。API 等待过长可以剪掉等待片段，并标注剪辑，不要把离线规则称为在线生成。

| 时间 | 操作与讲解 |
|---|---|
| 0–12秒 | 展示标题：“这是我的个人参赛作品 PetSupport-Bench，研究宠物商城混合咨询中的风险响应与开放式评测，不是 AI 宠物医生。” |
| 12–50秒 | 点击“混合意图＋紧急风险”，点击“运行 Agent”。展示紧急提示、报告及“查看可审计过程”的实际调用状态：“订单问题中夹带风险，系统先响应风险，再生成就诊准备信息。” |
| 50–75秒 | 点击“信息不足＋追问”，点击“运行 Agent”。展示并填写追问表单：“信息不足先追问，已填写信息可以保留。本轮是否调用模型由页面明确记录。” |
| 75–105秒 | 切换“评测结果”，展示 A0/A3 真实分数、闸门次数及评分表下载；另打开最终报告第5节：“100条构造样本、39种表达；七维评分；4种情境好中差排序，以及48次重复与对抗评审。不是临床数据或人工一致性认证。” |
| 105–118秒 | “完整方案没有在总分上胜出。评测也发现否定句误报和边界评分波动，所以闸门次数不等于真实风险。我们公开失败记录和评审依据，便于复现和改进。” |

最终数字以 `results/final/summary.json` 与 `docs/experiment_report.md` 为准。不要使用旧 `live_A3_results.csv` 或模拟图表。

用 AQ 录制浏览器区域，导出不超过2分钟的 MP4 或 GIF。将视频作为活动附件提交，或上传至公开可访问位置，并把真实视频链接补入 README；此脚本本身不满足视频交付要求。
