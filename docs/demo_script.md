# Demo 录制参考

[已经录好的视频](../demo/demo.mp4)时长 67.57 秒。下面保留的是录制参考，不是视频逐字稿；视频录于记忆 v2 升级之前，主要展示聊天流程。

## 录制准备

打开 [本机页面](http://127.0.0.1:8501/)，刷新后使用 Hy3 在线模式。用户直接聊天，不需要先选择问题类型。用 AQ 录浏览器区域即可，避开密钥、`.env` 和账户控制台。

如果模型等待较久，可以剪掉等待片段并说明做过剪辑。调用失败时重新录制或保留错误说明，不把离线规则回复说成模型生成。

## 两分钟内的参考流程

| 时间 | 页面操作 | 可以怎么说 |
|---|---|---|
| 0–12 秒 | 展示首页 | “这是我做的 PetSupport-Bench，一个宠物咨询 Agent。我也为它设计了一套回答评分方法。” |
| 12–45 秒 | 输入“换的猫粮什么时候到？我家猫最近食欲不好” | “用户可能一句话说两件事。这里不用自己选类型，系统会识别订单和健康问题，继续问缺少的信息。” |
| 45–75 秒 | 回复“它3岁，今天上午开始，精神还可以。”，展示报告和调用记录 | “补充信息后会整理成报告。下面可以看到这一轮哪些内容由规则处理，哪些调用了 Hy3。” |
| 75–100 秒 | 打开“评测与项目”，展示结果表 | “我构造了 100 条样本，共 39 种表达，用七个维度评分，还做了好中差排序、重复评分和对抗测试。” |
| 100–115 秒 | 展示报告中的问题分析 | “结果里也有失败和规则误判，我都保留了。批量分数对应早期实验版本，后来的聊天和记忆功能有单独测试。项目只做科普和就诊准备，不做诊断或用药建议。” |

也可以换成狗的案例：开始新对话后输入“狗粮怎么还没到？另外我家狗刚吃了半块黑巧克力，现在看着没事。”，展示系统对已识别风险的回应。不需要把所有案例放进一个视频。
