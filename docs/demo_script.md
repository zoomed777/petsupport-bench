# 聊天版 Demo：不超过2分钟

实际录制视频已附：[demo.mp4](../demo/demo.mp4)，67.57秒。以下为参考脚本，并非视频逐字稿。

录制前打开 http://127.0.0.1:8501/ 并刷新。默认使用Hy3在线，不需要选择问题类别或填写宠物档案。不要录到.env、密钥和账户控制台。等待模型时间过长可剪掉等待片段，并标注剪辑。

| 时间 | 操作与台词 |
|---|---|
| 0–12秒 | 展示聊天首页：“这是我的个人参赛作品PetSupport-Bench，面向宠物商城咨询，研究健康风险响应与开放式回答评估。” |
| 12–45秒 | 在聊天框发送“换的猫粮什么时候到？我家猫最近食欲不好”。展示自动追问：“用户不需要选择类型，系统自己识别订单和健康信息，先了解宠物情况。” |
| 45–75秒 | 在同一个聊天框回复“它3岁，今天上午开始，精神还可以。”，展示报告与实际调用状态：“信息通过自然语言补充，聊天记录会保留。这里能够区分规则回复、信息提取和模型生成。” |
| 75–100秒 | 切换“评测与项目”，展示两配置结果、完整评分表和48次评审：“冻结实验使用100条构造样本、39种表达，七维评分，并验证判别力、重复性与对抗表现。聊天版是后续交互改进，不冒充已经重新完成批量实验。” |
| 100–115秒 | “我们也公开规则误报和失败案例，不把闸门次数当作真实风险。代码、原始输出与评审依据都可以复查。项目不做诊断、处方或剂量建议。” |

可选替换案例：打开侧栏“开始新对话”后发送“狗粮怎么还没到？另外我家狗刚吃了半块黑巧克力，现在看着没事。”，展示紧急响应；不用同时把所有案例塞进两分钟。

如果首次调用失败，照实展示错误或重新录制，不要把离线规则称为Hy3生成。
