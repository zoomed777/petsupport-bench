## 风险与预案

| 风险 | 预案 |
|---|---|
| Hy3 端点不可用/不稳定 | 先用规则引擎 + 桩输出完成评测框架开发；端点就绪后一键切换跑实验 |
| Hy3 结构化输出不稳 | schema 校验 + 重试 2 次；降级为文本解析 |
| Judge 分数波动大 | 三视角中位数 + temperature=0 + 固定 prompt；稳定性实验佐证 |
| 人工标注人力不足 | 标注界面降低操作成本，30 条控制在 2 小时内 |
| 工期溢出 | 砍 A2 配置（消融从 4 组降为 3 组），保 A0 vs A3 主对比 |
