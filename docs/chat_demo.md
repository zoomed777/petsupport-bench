# 聊天交互版

用户直接发送自然语言，不再选择场景类别或填写档案表格。内部仍然使用规则与Hy3的混合管线，不是无限制通用聊天机器人。

1. `ChatSession`保存本次对话的用户消息和补充信息，管线自动判断意图。
2. 信息不足时，追问作为助手消息显示；用户在同一个输入框继续回答。
3. 数字年龄、次数、持续时间有规则抽取。在线追问回复额外由Hy3提取对应信息，只接受确实出现在最新用户消息中的原文片段，不接受凭空补齐的值。
4. 紧急信号在信息提取前检查，不等待用户答完追问；模型增强仍受原管线护栏约束。
5. 每轮消息保留实际调用记录、错误与规则路径。报告可以下载。当前版开始新对话会清除事件上下文但保留稳定宠物档案；后续增加的跨宠物、纠错、预算和持久化见[记忆管理](memory_management.md)。

## 初版验证范围（提交8b66a0e）

13项聚焦回归测试通过，包括：纯聊天追问、用户原句、一次或分次补充、历史保留、新会话清空、拒绝没有原文依据的提取、紧急描述打断追问。浏览器已检查首次消息自动识别并显示追问。

真实Hy3两轮检查：发送“换的猫粮什么时候到？我家猫最近食欲不好”，得到mixed路由和3个问题；回复“它3岁，今天上午开始，精神还可以。”后生成报告，剩余问题0个，记录到2次调用（信息提取和生成），调用错误0个。

## 限制

当前已支持显式名字/物种切换和按宠物隔离；复杂指代、同名或多宠物同句仍可能需要澄清。词表、简单规则和模型提取均可能出错；用户应检查报告中的信息。没有真实查单和转人工能力，不提供诊断、处方或剂量。记忆升级另有28项回归与四轮真实调用验证，原初版的两次调用数不代表所有新版流程。

此版是演示交互改进，不是新一轮批量实验。`results/final/`仍对应提交6368460的冻结结果，不将其宣称为当前多轮聊天版本的成绩。
